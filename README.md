# iosand71.github.io

Static source for Iosand.com, hosted through GitHub Pages.

The homepage uses the Ink design, with live Italian and Japanese text.
The previous homepage is preserved at
[`archived/2026/homepage-original.html`](archived/2026/homepage-original.html)
with its own frozen stylesheet. It shares the original image and font assets.

The COVID-19 reports are archived, unmaintained snapshots in
[`archived/2026/`](archived/2026/). The year is the year of archiving, not the
year covered by the reports. They are no longer linked from the homepage.
